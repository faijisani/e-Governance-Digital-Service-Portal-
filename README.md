## About the Project

The e-Governance Digital Service Portal is a beginner-friendly web-based prototype designed to demonstrate how citizens can access selected government services digitally.

The portal allows users to view available services, submit an online application, select a document, generate an application ID and track the application status.

---

## Main Features

- Government service listing
- Online application form
- Applicant information collection
- Mobile number validation
- Document selection
- Automatic Application ID generation
- Application status tracking
- Responsive design
- Browser LocalStorage for demo data

---

## Available Services

The prototype contains the following services:

1. Birth Certificate
2. Income Certificate
3. Residence Certificate
